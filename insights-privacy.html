Insights privacy

This policy explains the current Windows desktop version of JackLight Tales Insights, a private analytics tool operated for JackLight Tales. It covers the app’s account connections and local data.

About Insights Privacy Terms

Information the app accesses

Insights reads information from accounts you authorise. The information available depends on the provider, the permissions you grant and the connector’s setup.

  • YouTube API Services: basic channel information and channel statistics returned by YouTube, including channel ID and name, subscribers, total views and video count; and an authorised daily analytics report for the requested period, including views, estimated minutes watched, likes, comments, shares and subscribers gained or lost. Saved snapshots contain channel identity, summary totals, a daily views series and the dates of the report and check.
  • TikTok: the app-specific account identifier (open_id), display name, follower count, likes count and video count, obtained using user.info.basic and user.info.stats.
  • Meta: the Pages you can manage for account selection, the selected Page’s ID and name, its linked Instagram account ID and username, and available aggregate follower, engagement, reach and view statistics.
  • Cloudflare: information needed to identify the configured website and aggregate visits, pageviews and hourly totals for the reporting period.
  • Connection information: API application identifiers and secrets you enter, authorisation and refresh tokens, token expiry times, selected account details, preferences, last-sync times and error messages. Local error logs may contain diagnostic details.

The app works with account-level and aggregate statistics. It does not request individual viewer or follower lists, audience members’ contact details, private messages or comment text. Aggregate totals may reflect a mixed-age audience, but the app does not identify individual children or collect information directly from children using the app. Insights is intended for authorised adults managing the accounts.

How the information is used

Information is used to connect the accounts you choose, retrieve and display their statistics, build a local history, show connection errors and create CSV exports when you request them. Automatic checks can run hourly while the app is open; you can turn them off in Settings.

The desktop app has no advertising, behavioural tracking or remote analytics-upload feature. It does not sell account data, publish it, send it to other social platforms or use it to train models. Exporting creates a file in a location you choose; you control what happens to that file afterwards.

Sign-in and external services

Google, TikTok and Meta sign-in takes place on the provider’s website in your browser. The app receives authorisation results through a temporary callback on your own computer. Your provider password is not requested or stored by Insights. Read-only access tokens let the app request the information you approve. Cloudflare access uses the API token you supply.

The app contacts the relevant provider directly to sign in, refresh access and request statistics. Those providers receive the request and ordinary network information such as your IP address and apply their own terms and privacy policies. Insights uses YouTube API Services; see the Google Privacy Policy. You can also read the TikTok Privacy Policy, Meta Privacy Policy and Cloudflare Privacy Policy.

Where information is stored

On Windows, the app stores its data in %LOCALAPPDATA%\JackLight Tales Insights\Data for the current Windows user.

  • credentials.dat contains saved credentials and tokens protected by Windows DPAPI for that Windows user.
  • insights.db is an unencrypted SQLite database containing saved analytics snapshots, including account identifiers and names.
  • settings.json contains unencrypted preferences, selected account details and connection status.
  • The logs folder holds local diagnostic logs. CSV exports are also unencrypted files.

Insights does not upload these files to a JackLight Tales server or provide its own cloud backup or synchronisation. Other software on your computer, backup services or people with access to your Windows account may be able to access local data. Keep exported files and backups under your control.

Retention, disconnecting and revoking access

The current version keeps saved snapshots until they are deleted locally; it has no automatic history expiry. A new snapshot is normally saved when the returned values change.

Where a connection shows Disconnect in Settings, that action clears its saved access tokens and selected account information. Website disconnect clears its saved API connection details. Disconnecting does not delete historical snapshots, exports or backups. The social connectors retain their application configuration, such as client IDs and application secrets, until you remove the app’s local data.

To revoke a provider’s permission, also remove Insights in that provider’s account settings. For Google, use Google’s third-party access settings. TikTok and Meta provide controls for connected apps in their account settings. A Cloudflare API token can be revoked from the Cloudflare dashboard. Revocation stops future authorised access once the provider applies it; it does not itself erase previously saved local files.

Deleting the app’s local data

To remove all locally stored Insights history, credentials, settings and logs:

  1. Close JackLight Tales Insights completely.
  2. Open File Explorer and enter %LOCALAPPDATA%\JackLight Tales Insights\Data in its address bar. You can also open this location through Settings → Open Data Folder before closing the app.
  3. Delete the contents of that Data folder. This removes the local data for every connector, so only do this when you intend to clear the whole app.
  4. Delete any CSV exports or separate backups you want removed, including copies in the Recycle Bin or backup storage under your control.

The app creates a fresh data folder when next opened. This process does not delete content or statistics held by Google, TikTok, Meta or Cloudflare, and it does not replace revoking access in their account settings. If you need help with local deletion or a privacy question, contact contact@jacklighttales.com.

Website visits and email

These public information pages are separate from the desktop app. Visiting them creates ordinary website hosting requests; the JackLight Tales website privacy page covers the website. If you email us, the message and the contact details you include are received so we can respond. Do not include passwords, access tokens or application secrets in an email.

Questions and changes

For questions or complaints about Insights privacy practices, contact contact@jacklighttales.com. This page’s update date identifies the version of this explanation. Its description will need to be updated if the app’s data handling changes.
