Insights

JackLight Tales Insights is a private Windows desktop dashboard for the people managing JackLight Tales accounts. It brings authorised account statistics and website totals into one place.

About Insights Privacy Terms

What the app does

Insights connects directly to the services you authorise, displays the statistics they return and saves local snapshots so you can see changes over time. You can refresh manually, enable hourly checks while the app is running and export the saved summary values to a CSV file.

  • YouTube: channel totals and a recent analytics report, including views, watch time and engagement counts.
  • TikTok: the authorised account’s display name, follower count, total likes and video count, using Login Kit and the profile statistics API.
  • Meta: the selected Facebook Page and its linked Instagram account, with the account totals and insights that Meta permits.
  • Website: aggregate visits and pageviews returned by Cloudflare Web Analytics.

The connectors are being configured and tested for private use. Each connection depends on the account’s permissions, the provider’s available APIs and any required provider approval. This page does not mean every connector is currently active.

You choose the access

Google, TikTok and Meta handle sign-in in your browser. Insights requests access to read account information and analytics. It has no posting, messaging or account-editing features. The website connection uses an API token supplied by the account owner.

For TikTok, the requested permissions are user.info.basic and user.info.stats. They allow Insights to identify the account you authorise and read its follower, likes and video totals.

Stored on your computer

Analytics history stays in the app’s local data folder. On Windows, saved access credentials are protected with Windows DPAPI. The app does not send your snapshots to a JackLight Tales server or sync them between computers. Read the privacy policy for the details, including how to disconnect, revoke access and delete local data.

Who it is for

Insights is an account-management tool for authorised adults managing JackLight Tales. It is separate from the children’s story website and has no public sign-up or download on this page.
