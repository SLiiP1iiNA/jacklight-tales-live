# Barnaby audiobook drop folders

You do not need to edit the website when an episode audio file is ready.

1. Export the narration as an MP3.
2. Name it `episode-001.mp3`, replacing `001` with the real three-digit episode number.
3. Put it in the matching series folder below.
4. Refresh the website and open **Listen to the tales**. The episode will unlock automatically.

| Series | Folder | Required episode filenames |
| --- | --- | --- |
| 1 | `series-01` | `episode-001.mp3` to `episode-030.mp3` |
| 2 | `series-02` | `episode-031.mp3` to `episode-060.mp3` |
| 3 | `series-03` | `episode-061.mp3` to `episode-090.mp3` |
| 4 | `series-04` | `episode-091.mp3` to `episode-120.mp3` |
| 5 | `series-05` | `episode-121.mp3` to `episode-150.mp3` |
| 6 | `series-06` | `episode-151.mp3` to `episode-180.mp3` |

The spelling, hyphen and three digits matter. Keep file extensions visible in Windows Explorer so a file does not accidentally become `episode-001.mp3.mp3`.

The library only checks the series a visitor opens, so it does not make 180 checks at once. Missing audio is safe: its episode button simply remains locked.
